## Troubleshooting

### "Authentication failed"
- Make sure you're using a Personal Access Token
- Not your GitHub password
- Token should start with `ghp_`

### "Still asking for password after storing"
- That's fine! It will only ask once
- Next push won't need password (credentials stored)

### "Repository not found"
- Verify URL: https://github.com/surajuniyal073/assignment2_Converstational_AI
- Make sure repository exists on GitHub
- Verify you have access

### "Connection timeout"
- Check your internet connection
- Try again in a few seconds
- If persistent, verify GitHub is not down
